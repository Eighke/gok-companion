# GoK Companion

Calculators, planners, event guides and a daily task tracker for the mobile game GoK, as a desktop
app for **Windows**, **macOS** and **Linux**.

> GoK Companion is an **unofficial, fan-made** tool. It is not affiliated with or endorsed by the
> game's developer or publisher.

This repository only hosts the downloads. The app is free.

- **Website** (tools and guides in your browser): https://gokhans.pages.dev
- **Android:** [Google Play](https://play.google.com/store/apps/details?id=th.co.snowdigital.gokcompanion)

## Download

Get the latest version from **[Releases](../../releases/latest)**:

| System | File |
|---|---|
| Windows 10 / 11 | `GoK.Companion_<version>_x64-setup.exe` (or the `.msi`) |
| macOS (Intel and Apple Silicon) | `GoK.Companion_<version>_universal.dmg` |
| Linux | `.AppImage` (any distribution), `.deb` (Debian, Ubuntu) or `.rpm` (Fedora, openSUSE) |

The `.app.tar.gz` file is used for automatic updates; you don't need it.

## First launch

The app isn't signed with a paid certificate, so your system warns you the first time:

- **Windows:** "Windows protected your PC" → **More info** → **Run anyway**.
- **macOS:** right-click the app → **Open** → **Open**. If macOS still refuses, open
  **System Settings → Privacy & Security** and click **Open Anyway** next to GoK Companion.
- **Linux (AppImage):** make the file executable (`chmod +x GoK.Companion_*.AppImage`), then run it.

## Your data

Everything is stored on your device. If you connect Google Drive, your data is also synced to your own
Drive's hidden app folder, and nowhere else: no server, no analytics, no ads.
[Privacy policy](https://gokhans.pages.dev/privacy/).
